# Landlords Toolkit — Product Blueprint

## Core Idea

A collection of low-liability landlord assets that rank through search and sell repeatedly.

The product should solve professional landlord problems without becoming a high-liability property-management platform.

## Target Users

- small landlords with 1–100 units
- property owners
- rental arbitrage operators
- DIY property managers
- HOA managers
- property maintenance managers

## Free SEO Layer

Free assets should require no login and no account.

Initial asset categories:

- maintenance request templates
- complaint letters
- late rent notices
- lease renewal letters
- move-in checklists
- move-out checklists
- rent ledger spreadsheets
- security deposit letters
- maintenance logs

## Premium Layer

One-time purchase model:

- premium forms library
- spreadsheet suite
- state packs
- inspection packs
- incident report packs

Target price range:

```txt
$29–$99
```

## AI Tool Layer

Future tools should be stateless.

Allowed pattern:

```txt
Input → Generate → Return → Delete
```

Avoid permanent storage unless the user explicitly creates an account in a later product version.

Potential generators:

- late rent notice generator
- noise complaint generator
- maintenance acknowledgment generator
- lease renewal letter generator
- pet violation letter generator
- parking violation notice generator
- move-out reminder generator
- repair completion notice generator
- vendor communication generator

## Calculator Layer

No account required.

Initial calculators:

- cash flow calculator
- cap rate calculator
- ROI calculator
- rehab budget calculator
- rent increase calculator
- vacancy loss calculator

## Content Hub

Long-term SEO engine:

- 300+ articles
- state law overview pages
- form-specific guides
- spreadsheet tutorials
- checklist examples
- landlord organization tips

## What To Avoid

Avoid features that create liability or support burden:

- rent collection
- ACH/payment processing
- tenant screening
- credit reports
- SSN collection
- bank data
- tenant portals
- maintenance ticket storage
- CRM-style tenant profiles
- high-liability legal workflows

## Success Pattern

```txt
SEO article
↓
Free template/tool
↓
Optional email capture
↓
Premium bundle
↓
Affiliate products
↓
Future AI upgrade
```

## Brand Positioning

Simple message:

> Free landlord forms, spreadsheets, and calculators. No account required.

More direct message:

> Download the form, use the calculator, solve the problem, move on.
